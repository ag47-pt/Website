# Higgsfield Studio (Diretor de Criação)

This skill orchestrates sequential video generation using Higgsfield AI by enforcing visual continuity, storyboard consistency, and narrative fidelity. It mandates a Pre-Production Gate to assemble style guidelines, character profiles, and a visual scene mosaic before animating the scenes.

---

## The Pre-Production Gate (Ficha Técnica de Criação)

Before any video generation starts, the skill must assemble and present a **Ficha Técnica de Criação** (Creative Spec Sheet). This serves as the master blueprint to validate consistency and prevent divergence during production. 

The **Ficha Técnica de Criação** consists of:
1. **Guia de Estilo (Style Guide)**: Color palette, camera angles, lens specifications, atmospheric lighting, and overall visual tone.
2. **Ficha de Personagens (Character Profiles)**: Description of all characters (age, hair, facial features, outfits) along with their visual reference images generated locally.
3. **Mosaico de Cenas do Storyboard (Scene Mosaic)**: A structured grid detailing the narrative flow, visual action, and prompts for the keyframe images (initial and final frames) for every scene.
4. **Visual Aids**: Generation of the character visual sheets and a storyboard layout mock-up/preview using local image generation tools (`generate_image`).

This Gate must be approved by the user or validated before submitting video rendering jobs to Higgsfield.

---

## Enforcing Visual Continuity (Frame-to-Frame)

To ensure a continuous and seamless narrative across scenes (e.g., motion videos), the skill follows a strict keyframe chain:

1. **Scene 1**: 
   - Generate `Scene_1_Start_Image` (initial frame).
   - Generate `Scene_1_End_Image` (final frame).
   - Video 1 is generated by animating from `Scene_1_Start_Image` to `Scene_1_End_Image`.
2. **Scene 2**:
   - The start image is automatically defined as: `Scene_2_Start_Image` = `Scene_1_End_Image` (the final image of the previous scene).
   - Generate `Scene_2_End_Image` (final frame).
   - Video 2 is generated by animating from `Scene_2_Start_Image` to `Scene_2_End_Image`.
3. **Scene N** (for $N > 2$):
   - `Scene_N_Start_Image` = `Scene_N-1_End_Image`.
   - Generate `Scene_N_End_Image`.
   - Video N is generated by animating from `Scene_N_Start_Image` to `Scene_N_End_Image`.

This creates a linked visual chain where each video starts exactly where the previous one finished.

## Workflow

### Phase 1 — Storyboard & Pre-Production Gate (Ficha Técnica)
1. **Analyze Theme & Concept**: Identify the theme provided by the user (e.g., commercial campaign, entertainment/novela, promo) and target format/aspect ratio.
2. **Create the Ficha Técnica de Criação**:
   - Write down the **Guia de Estilo** (color, lighting, atmosphere).
   - Define **Ficha de Personagens** for each key character.
   - Generate visual references for characters using local tools (`generate_image`).
   - Draw up the **Storyboard Scene Mosaic**: for each scene, document Scene Number, Style Directives, Visual Action (transition), Start Frame prompt, and End Frame prompt.
3. **Validation**: Present the Ficha Técnica to the user. Proceed to Phase 2 only after confirmation.

### Phase 2 — Keyframe Generation (Local LLM / Tools)
For each scene, generate the keyframes. Note that we do **NOT** use Higgsfield for generating the static images; we use local generation:
1. **First Scene (Scene 1)**:
   - Use the local image generation tool/model (e.g. `generate_image` or external APIs) to generate `Scene_1_Start_Image` and `Scene_1_End_Image` ensuring they strictly adhere to the Ficha Técnica.
2. **Subsequent Scenes (Scene N)**:
   - Reuse `Scene_N-1_End_Image` as the starting point.
   - Generate `Scene_N_End_Image` using the local image generation tool/model. **Crucial**: Incorporate structural and style guidelines from the Style Guide and reference the visual details of the preceding image to preserve style, lighting, and object consistency.

### Phase 3 — Video Generation (Higgsfield Seedance 2.0)
For each scene $i$, once both `Scene_i_Start_Image` and `Scene_i_End_Image` are generated/available, submit the video generation job via `higgsfield-generate` (Seedance 2.0):

```bash
higgsfield generate create seedance_2_0 \
  --prompt "Camera transition and animation description matching the scene's Visual Action" \
  --start-image "/path/to/Scene_i_Start_Image" \
  --end-image "/path/to/Scene_i_End_Image" \
  --duration 4 \
  --aspect_ratio <aspect_ratio> \
  --wait
```

### Phase 4 — Final Delivery
Deliver the sequential list of generated video URLs along with their storyboard context so the user can download and stitch them together.
