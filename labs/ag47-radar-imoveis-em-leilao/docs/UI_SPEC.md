# UI Spec - Radar Leilão

## Layout
- Hero com headline forte e CTA primária
- Formulário lateral com campos financeiros
- Resultado com score e recomendação
- Sessão de benefícios e casos de uso

## Design tokens
- Background: preto/verde profundo
- Accent: verde claro
- Text: branco neutro
- Muted: cinza esverdeado
- Radius: 12-24px
- Shadow: sutil com glow verde

## Fluxo principal
1. Usuário acessa landing page
2. Preenche valores do imóvel
3. Sistema calcula risco e yield
4. Resultado mostra recomendação

## Critérios de aceite
- Mobile responsivo
- CTA visível na dobra
- Resultado aparente sem refresh
- Mensagens de recomendação claras
