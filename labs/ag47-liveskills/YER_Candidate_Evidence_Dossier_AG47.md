# 14. Regras de honestidade para a landing `/yer`

1. Não dizer que o candidato é ML Engineer.
2. Não atribuir anos de experiência sem confirmação.
3. Não dizer “expert” em tecnologias apenas utilizadas.
4. Não apresentar features planejadas como implementadas.
5. Não apresentar documentação conceitual como código production-ready.
6. Não esconder o uso de IA.
7. Não diminuir a autoria humana por usar IA.
8. Sempre que possível, provar uma capacidade com projeto, arquitetura, código, teste ou produto.
9. Preferir “built”, “designed”, “implemented”, “integrated”, “structured” e “evolved” quando houver evidência.
10. Usar “explored”, “prototyped” ou “designed” quando o trabalho ainda não tiver maturidade de produção.
