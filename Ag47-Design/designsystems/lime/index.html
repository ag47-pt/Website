Accordion
Lima é um sistema de design completo com tokens semânticos, componentes interativos e padrões prontos para uso. Construído sobre verde limão, violeta vibrante, preto e branco.
Use sempre os tokens semânticos (`--bg`, `--text`, `--lime`, etc.) em vez de cores literais. Eles se adaptam automaticamente ao tema.
Veja a seção Migration Guide no markdown. As principais mudanças são: unificação do `--lime`, outline badges via `--text`, novos componentes.

Do & Don't

Exemplos visuais de uso correto vs incorreto. Aprenda com contraste.

✓ DO
Vermelho só para erros críticos
Erro crítico
Vermelho é exclusivo semântico. Comunica claramente: algo precisa de atenção urgente.
✗ DON'T
Não use vermelho decorativamente
Destaque
Vermelho decorativo dilui seu significado. Quando o erro REAL aparecer, o usuário não vai notar.
✓ DO
Outline badges para hierarquia visual
Em revisão Beta Em destaque
Outline adiciona cor sem peso visual. Use quando o badge é secundário ao conteúdo.
✗ DON'T
Não misture muitas cores em sequência
A B C D E F
Muitas cores competem por atenção. Limite a 2-3 cores simultâneas para manter clareza.

Hierarquia? → Breadcrumb

Preciso de feedback de estado?

Carregando? → Skeleton

Perguntas Frequentes

Respostas para as dúvidas mais comuns sobre o Lima Design System.

Baixe o arquivo CSS de tokens, defina as variáveis no :root, e importe os componentes que precisar. Tudo é vanilla CSS — sem dependências.

Veja a seção Migrar de v1.0 no markdown para breaking changes.

Sim! Lime funciona com qualquer accent. Purple é o recomendado pela harmonia triádica, mas você pode definir um accent customizado via --accent.

Defina um novo seletor no CSS: :root[data-theme="meu-tema"] { /* tokens */ }. Adicione a opção no toggle JS. Mantenha os tokens semânticos (--bg, --text, etc).

Sim. Todos cumprem WCAG 2.1 AA no mínimo. Focus ring consistente, ARIA correto em componentes interativos, suporte a prefers-reduced-motion e prefers-color-scheme.

Zero dependências significa: zero build step, zero lock-in, zero conflito de versões. Funciona em qualquer stack. Você pode usar os tokens em qualquer framework.

Adicione o componente em uma nova seção do markdown, documente tokens e variantes, e adicione o showcase na landing page. Mantenha consistência com os tokens existentes.
